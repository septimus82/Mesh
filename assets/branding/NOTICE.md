# MeshMind Studios brand assets

The images in this folder are adaptations of the MeshMind Studios logo. They are © MeshMind Studios, all rights
reserved.

- **The "MeshMind Studios" wordmark** (`meshmind_studios_wordmark.png`) is the publisher's credit.
- **The brain-and-network mark** (`mesh_studio_mark_*.png`, `mesh_studio_icon_*.png`) is Mesh Studio's application
  icon. It is shown beside the product name.

**They are not covered by the Mesh Engine code licence**, whatever that licence is or becomes. Forks and other
projects may not use them to brand their own software.

The original logo's design and cyan colour are kept. The only adaptation is light ink (`#E2E8F0`) in place of the
original navy, so the mark reads on Mesh Studio's dark surfaces. The icons put the mark on a graphite tile.
